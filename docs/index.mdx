---
title: Get started with Zeabur Builder
description: Build images from Git with BuildKit on Kubernetes, and pass the results to your deployment tool.
---

Zeabur Builder is a Kubernetes operator. You create a `Build` that points to a Git repository. Zeabur Builder builds an image for each new commit, pushes the image to a registry, and writes `<repository>:<tag>@<digest>` to `status.latestImage`.

Zeabur Builder only builds images. Your pipeline, deployment tool, and log collector handle testing, deployment, and log storage.

<Callout type="info">

Zeabur Builder has no releases yet, and its API is `v1alpha1`. This documentation describes the current behavior of the `main` branch.

</Callout>
