---
title: 推送到外部镜像仓库
description: 配置推送凭据，将 Build 生成的镜像推送到外部镜像仓库。
---

在 Build 所在的 Namespace 创建推送用的 Secret，并在 Build 中指定镜像和 Secret，就能将镜像推送到 `registry.host` 以外的镜像仓库（registry）。

<Steps>

<Step>

### 创建推送用的 Secret

在 Build 所在的 Namespace 创建 `kubernetes.io/dockerconfigjson` 类型的 Secret，并添加 `builder.zeabur.com/push-credentials: "true"` 标签：

```sh
kubectl -n team-a create secret docker-registry ghcr-push \
  --docker-server=ghcr.io --docker-username=acme --docker-password=<token>
kubectl -n team-a label secret ghcr-push builder.zeabur.com/push-credentials=true
```

</Step>

<Step>

### 在 Build 中指定镜像和 Secret

将 Build 的 `spec.output.image` 设为外部 registry 的镜像名称，并在 `spec.output.pushSecretRef` 中指定 Secret：

```yaml
spec:
  output:
    image: ghcr.io/acme/api
    pushSecretRef: {name: ghcr-push}
```

如果 Secret 包含 `registry.host` 条目，本次 run 的令牌会替换这个条目。

</Step>

</Steps>

## 遇到问题

| 界面或结果 | 处理方法 |
| --- | --- |
| run 停在 `RegistryCredentialsMissing` 状态等待 | 确认 Build 所在的 Namespace 中有指定的 Secret，且 Secret 带有 `builder.zeabur.com/push-credentials: "true"` 标签。 |
