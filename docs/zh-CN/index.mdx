Zeabur Builder 是一个 Kubernetes operator。你创建一个 `Build`，指向 Git 仓库。Zeabur Builder 会为每个新 commit 构建镜像，推送到镜像仓库，并把 `<repository>:<tag>@<digest>` 写入 `status.latestImage`。

Zeabur Builder 只构建镜像。测试、部署和日志存储交给你的 pipeline、部署工具和日志收集工具。

<Callout type="info">

Zeabur Builder 还没有发行版，API 是 `v1alpha1`。这份文档描述 `main` 分支当前的行为。

</Callout>
