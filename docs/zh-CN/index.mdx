Zeabur Builder 把 Git 仓库变成可以运行的镜像。它用 [Railpack](https://railpack.com) 识别代码使用的语言（Node.js、Python、Go、PHP、Ruby、Java、Rust、Elixir、Deno、.NET、Gleam、C++、Zig、静态网站和 shell 脚本），按你的 Dockerfile 构建，或用 [AI 构建器](builds/ai-builder.mdx)让模型写一份，之后分支一有更新就会重新构建。

## 我在用 Zeabur 开源版

Zeabur 开源版会帮你安装和运行 Zeabur Builder，不需要自己安装或配置。

- Zeabur Builder 是 Zeabur Catalog 里的组件。集群还没装的话，打开**集群** → **组件**，找到 Zeabur Builder 后点击**安装**，见[查看和安装集群组件](https://oss.zeabur.com/zh-CN/docs/zeabur/cluster/components/)。
- 要从 Git 部署，在项目中选择**新增** → **从 Git 部署**，见[从 Git 构建并部署服务](https://oss.zeabur.com/zh-CN/docs/zeabur/deploy/git/)。

安装 Zeabur 开源版和管理服务的方法，见 [Zeabur 开源版文档](https://oss.zeabur.com/zh-CN/docs/zeabur/)。

## 我要单独使用 Zeabur Builder

Zeabur Builder 是一个 Kubernetes operator。你创建一个 `Build`，指向 Git 仓库。Zeabur Builder 会为每个新 commit 构建镜像，推送到镜像仓库，并把 `<repository>:<tag>@<digest>` 写入 `status.latestImage`，交给你的部署工具。

Zeabur Builder 只构建镜像。测试、部署和日志存储交给你的 pipeline、部署工具和日志收集工具。

<Callout type="info">

API 版本是 `v1alpha1`。升级前请先阅读[更新日志](../../CHANGELOG.md)。

</Callout>
