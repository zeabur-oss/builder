---
title: 部署建置好的映像檔
description: 使用可排序的 tag 搭配部署工具，並設定 Build 在建置成功後通知 Keel。
---

使用可排序的 tag，讓 Flux image automation、Argo CD Image Updater 與 Keel 在輪詢 registry 時找到新映像檔。設定 `spec.notify` 後，`Build` 會在每次建置成功後通知 Keel，不必等待下一次輪詢。

## tag 格式

每次建置都會產生一個 tag，依序包含分支名稱、Unix time 與 commit：

```text
main-1761058800-3e1a9c2
```

這些 tag 可以排序，最新的 tag 會排在最後。你可以用 `spec.output.tagTemplate` 與 `extraTags` 調整 tag。

## 通知 Keel

在 `Build` 的 `spec.notify` 加入 Keel webhook：

```yaml
spec:
  notify:
    - {type: keel, url: http://keel.keel.svc:9300/v1/webhooks/native}
```

每次建置成功後，控制器會送出以下內容：

```text
{"name": <repository>, "tag": <tag>}
```

`name` 是映像檔的 repository，`tag` 是建置產生的 tag。控制器會嘗試 3 次，並將通知結果記錄在 `Build` 的 Event 中。

## 確認結果

檢視 `Build` 的 Event，確認 Keel 通知結果。
