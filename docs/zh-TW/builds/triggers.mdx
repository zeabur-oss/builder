title: 觸發建置

你可以用輪詢、push webhook、[GitHub App](./private-repos.mdx) 或手動重建來觸發 Zeabur Builder 建置。

## 輪詢

控制器預設每分鐘向 Git 伺服器查詢一次 ref。你可以用 `spec.triggers.pollInterval` 設定輪詢間隔。

## 設定 push webhook

push webhook 會喚醒追蹤該儲存庫與分支的 Build。

<Steps>

<Step>

### 啟用接收器

在 Helm chart 中啟用 `webhooks.enabled`，再設定 `webhooks.ingress` 或 `webhooks.httpRoute`。

</Step>

<Step>

### 指定 Build 的 Secret

在每個 Build 的 `spec.triggers.webhook.secretRef` 指定 Secret 名稱與 key：

```yaml
spec:
  triggers:
    webhook: {secretRef: {name: api-webhook, key: secret}}
```

</Step>

<Step>

### 設定儲存庫的 webhook

將儲存庫的 webhook 網址設為 `https://<host>/hooks/<provider>`，並使用與 Secret 相同的密鑰。

依照你使用的 Git 服務選擇 `<provider>`：

| 服務 | `<provider>` |
| --- | --- |
| GitHub | `github` |
| GitLab | `gitlab` |
| Gitea | `gitea` |
| Forgejo | `forgejo` |
| Bitbucket | `bitbucket` |
| [Standard Webhooks](https://www.standardwebhooks.com/) | `generic` |

啟用 push webhook 後，控制器仍會持續輪詢。

</Step>

</Steps>

## 手動重建與暫停自動建置

將 Build 的 `builder.zeabur.com/rebuild` annotation 改為新值，就能重新建置目前的 commit。

你可以用 `spec.suspend` 停止自動建置。

## 處理執行中的建置

你可以用 `spec.concurrency` 設定新 commit 到來時，要如何處理執行中的建置：

| 設定值 | 行為 |
| --- | --- |
| `Replace`（預設） | 取消執行中的建置。 |
| `Queue` | 讓執行中的建置完成。 |
