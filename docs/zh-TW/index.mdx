Zeabur Builder 是一個 Kubernetes operator。你只要建立一個 `Build`，指定 Git 儲存庫，Zeabur Builder 就會為每個新 commit 建置映像檔，再推送到 registry。完成後會把 `<repository>:<tag>@<digest>` 寫進 `status.latestImage`。

Zeabur Builder 只負責建置映像檔。測試、部署和日誌儲存則交給你的 pipeline、部署工具和日誌收集工具。

<Callout type="info">

Zeabur Builder 還沒有發行版，目前的 API 是 `v1alpha1`。這份文件說明 `main` 分支目前的行為。

</Callout>
