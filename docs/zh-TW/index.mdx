Zeabur Builder 把 Git 儲存庫變成可以執行的映像檔。它用 [Railpack](https://railpack.com) 判斷程式碼用的語言（Node.js、Python、Go、PHP、Ruby、Java、Rust、Elixir、Deno、.NET、Gleam、C++、Zig、靜態網站和 shell 腳本），依照你的 Dockerfile 建置，或用 [AI 建置器](builds/ai-builder.mdx)讓模型寫一份，之後分支一有更新就會重新建置。

## 我在用 Zeabur 開源版

Zeabur 開源版會幫你安裝和執行 Zeabur Builder，不需要自己安裝或設定。

- Zeabur Builder 是 Zeabur Catalog 裡的元件。叢集還沒有裝的話，打開**叢集** → **元件**，找到 Zeabur Builder 後按**安裝**，見[檢視與安裝叢集元件](https://oss.zeabur.com/zh-TW/docs/zeabur/cluster/components/)。
- 要從 Git 部署，在專案裡選**新增** → **從 Git 部署**，見[從 Git 建置並部署服務](https://oss.zeabur.com/zh-TW/docs/zeabur/deploy/git/)。

安裝 Zeabur 開源版和管理服務的方式，見 [Zeabur 開源版文件](https://oss.zeabur.com/zh-TW/docs/zeabur/)。

## 我要單獨使用 Zeabur Builder

Zeabur Builder 是一個 Kubernetes operator。你只要建立一個 `Build`，指定 Git 儲存庫，Zeabur Builder 就會為每個新 commit 建置映像檔，再推送到 registry。完成後會把 `<repository>:<tag>@<digest>` 寫進 `status.latestImage`，交給你的部署工具。

Zeabur Builder 只負責建置映像檔。測試、部署和日誌儲存則交給你的 pipeline、部署工具和日誌收集工具。

<Callout type="info">

API 版本是 `v1alpha1`。升級前請先讀[更新紀錄](../../CHANGELOG.md)。

</Callout>
